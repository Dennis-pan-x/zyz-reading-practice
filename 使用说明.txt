PASSAGE by ZYZ 使用说明｜2026-10-07-r2

一、更新前先备份
在能看到记录的版本中，进入“记录”，下载完整备份，保留 JSON 文件和旧网页，再打开新版。
新版没有显示旧记录时，在“记录 → 数据恢复”导入备份。升级后请继续使用新版。旧版可能看不到记录；回到新版查看即可，不要清空记录或清理浏览器数据。

二、先解压，再打开
把 ZIP 完整解压到电脑上的普通文件夹，用 Chrome 打开其中的 HTML 网页。
不要在压缩包内直接打开，也不要通过微信、QQ、网盘或系统的预览窗口打开。解压后可离线练习，本版本供电脑使用。

三、平时定期备份
记录保存在当前浏览器中。更换电脑或浏览器、移动网页、清理浏览器数据前，请先下载完整备份。
有新内容需要备份时，首页会适时提醒。也可以随时在“记录”页点击“立即完整备份”。确认浏览器下载列表里已有 JSON 文件，并妥善保留。
上次下载日期在“备份与导入说明”中查看。备份之后新增的内容，需要再次备份才能保留。

四、保存遇到问题
先不要关闭或刷新网页，按弹窗提示重试保存。
仍无法保存时，点击“下载练习文件”，再按提示选择刚下载的文件。网页会自动核对并尝试恢复。成功后，按提示继续作答、重试保存或查看复盘。
仍不能保存时，请留好练习文件。之后在能够正常保存的新版中，从“记录 → 数据恢复”导入：可识别且与当前内容匹配的未完成练习可继续作答；已提交的内容可重试保存，复盘内容可恢复笔记和标注。遇到不匹配提示时，请保留文件和旧版网页，不要清空数据。
“已安全保存”表示学习记录已保存；“内容已保留在练习文件中”表示需要留好文件，之后导入。诊断文件只用于排查，不能恢复记录。

五、无法开始练习，或一直保存失败
先使用浏览器普通窗口，关闭其他打开的 PASSAGE 页面。
在“记录”页尾的“更多操作”中，选择“修复保存问题”。下载修复备份后，点击“选择备份文件并修复”，选择刚下载的 JSON 文件；网页会核对文件、重新建立保存状态并恢复学习内容。
如果仍有问题，留好备份，不要清理浏览器缓存或数据。可以换另一浏览器的普通窗口打开新版，再导入备份。备用方案也失败时，下载诊断文件发给老师排查。
如果需要先练习，可按启动弹窗提示选择临时练习或模考。结束或中途退出时，会提示下载本次“练习文件”；按提示选择文件核对后再退出。临时练习不会自动加入浏览器中的学习记录，之后可在能正常保存的新版中导入文件。

六、恢复完整备份
在“记录 → 数据恢复”选择备份文件，选择“完整备份”后，网页会核对可恢复的学习记录、笔记、未完成进度和界面设置。请按结果提示核对；部分旧进度或不匹配的内容可能无法恢复，原备份请继续保留。
如果只想找回某次之前保存的进度，展开对应列表，按篇名、保存时间和状态选择。恢复后查看页面结果；较新的本机学习内容会保留。

七、在其他平台或纸质材料上练习过
其他平台的备份不能直接导入。可在练习页点击“管理练习状态”，选择文章后“标为已练习”；只记录练习进度，不会补入原平台的成绩、用时或笔记。手动标记会随完整备份保存。

八、网页打不开
确认已完整解压、打开的是 HTML 文件，并使用电脑浏览器。仍打不开时，可以重新下载并解压一份，保留原网页和已有备份。换浏览器不会自动带走原浏览器里的记录。

九、答案更新与旧记录
本版更新了 Understanding climate change 的一组多选答案。旧记录保留提交时的答案、成绩、用时和笔记；再次练习使用当前标准答案。

十、本次答题要求更新
判断、标题匹配与填空等题型的要求已统一，各题的字数、数字、多选和重复使用规则保留。已识别的旧记录保留当时的题面和笔记；再次练习使用本版要求。
